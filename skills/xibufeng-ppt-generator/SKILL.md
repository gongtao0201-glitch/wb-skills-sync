```python
def set_shape_text(shape, paragraphs):
    """替换文字，保留形状原有格式。paragraphs: str 或 list[str](每段落一行)"""
    if isinstance(paragraphs, str):
        paragraphs = [paragraphs]
    tf = shape.text_frame
    existing = list(tf.paragraphs)
    for i, txt in enumerate(paragraphs):
        if i < len(existing):
            para = existing[i]
            if para.runs:
                para.runs[0].text = txt
                for r in para.runs[1:]:
                    r.text = ""
            else:
                para.add_run().text = txt
        else:
            tf.add_paragraph().text = txt
    for j in range(len(paragraphs), len(existing)):
        for r in existing[j].runs:
            r.text = ""

def set_cell(cell, text):
    """设表格单元格文字，清空多段落残留"""
    tf = cell.text_frame
    paras = list(tf.paragraphs)
    if paras and paras[0].runs:
        paras[0].runs[0].text = str(text)
        for r in paras[0].runs[1:]:
            r.text = ""
    elif paras:
        paras[0].add_run().text = str(text)
    else:
        cell.text = str(text)
    for p in paras[1:]:
        for r in p.runs:
            r.text = ""

def shape_by_name(slide, name):
    for s in slide.shapes:
        if s.name == name:
            return s
    return None
```

## 踩坑记录

1. **字体格式丢失**：用`shape.text = xxx`会清空格式，必须用`set_text_keep_format()`
2. **产品分类瞎猜**：窝料78.4%/饵料1.6%的荒谬结果，必须从历史PPT反推+用户确认
3. **数据未清洗**：原始Excel含空商品名异常行，必须过滤
4. **跨月份硬凑比例**：不同时期数据不同，不能硬凑比例
5. **自有/通货毛利率算错**：必须按"商品名称含'自有'"判断，实时计算
6. **毛利率用了Excel列**：用户明确说"直接加权平均不对"，必须用`(销售金额-成本价×数量)/销售金额`，不用Excel的`销售毛利率`列
7. **饵料/窝料占比范围错**：第1页只按**前10名**算，两者归一化=100%；不要按全量算（全量会含小药/配件导致不等于100%）
8. **前10名框误填总销售额**：`前10名销售额`框=前10合计，`X月电商销售`框=总销售额，两个都填真实值；6月版曾把总销售额误填进前10名框、电商销售框残留旧月份值
9. **残留旧月份标签**：复制上月版后，标题/电商销售框/第3页"X月计划"/差评表头里的旧月份必须全部改为当月

# 西部风产品分类规则（长期记忆）

## 数据来源
- 数据源：聚水潭发货数据（销售主题分析_商品5月.xlsx）
- 分类标准：基于4月PPT模板数据反推 + 用户确认的行业常识

## 分类规则（按优先级从上到下匹配）

### 饵料类
- 拉小米、原浆、破碎料、方块饵、血麦
- 空钩饵、空钩粘米、空钩粘粉
- 含"饵料"但不含"爆炸"、鱼饵、易杯饵、雾化饵、杯饵
- 完爆黑坑、野鲫风暴、狂野爆鲫
- 野鲫（腥/香）、共同富鱼、狂钓鲫、罗非
- 牛鲤三合一、牛B千里鲫、甜薯粒
- 蛋黄、重口味、狂鲤
- 阿鲢（鲢鱼饵/方块饵类，如"阿鲢 酸臭 慢800g"、"阿鲢 酸臭 快 800g"）→ 饵料

### 窝料类
- 维它米、谷麦、杂粮（不含握团）、牛窝、神窝
- 酒米、麝香米、打窝、玉米、黄颡鱼
- 颗粒（不含方块饵）、爆炸饵、含"窝"字（牛窝/神窝除外）
- 米团、速散、本草（本草纲目除外）、果酸嫩玉米、蜂蜜嫩玉米
- 打浮、草霸、巨物、狂米、色诱米
- 加强中草（含米）、麝香麦粒、升级版（含米）、老坛甜薯麦粒
- 一桶天下、西部风握团杂粮、五谷酿、维它药米、中草发酵米麦
- 神鲫米
- 米窝、红小米（如"600g鳞虾米窝碎红小米"、"十三香鸭屎碎红小米450g"、"600g鳞虾米窝红大米"）→ 窝料

### 小药/添加剂类
- 拉丝粉、粘粉（不含空钩粘粉）、小药
- 鲫粉、鲤粉、虾粉、蒜粉
- 红虫液、果酸（液体形态）
- 狂诱、开口、开口剂、麝香王、麝香酒
- 一滴、全能辅助、中药酒、药酒、浓缩液、喷剂
- 中农味觉、阿魏、VB
- 麝香味、红虫味、甜薯味
- 千里香、蛋奶（不含空钩）、南极虾粉
- 老坛粉、甜薯粉、肽甜香
- 麝香麦粒红（100ml包装）、泡米曲酒
- 鲫鱼老酒、鲤鱼老酒、酒源、红虫粉
- 快拉、鱼蟲宴（不含方块饵）
- 牛B（粉/水形态）

### 配件/其他
- 打窝杆、毛巾、水桶、失手绳、拉链袋、袋装
- 通用拉链白袋

## 特殊规则
- 含"米"字的产品大部分是窝料，但"拉小米"是特例（属于饵料）
- "鱼蟲宴方块饵"是饵料，但"中农鱼蟲宴30g"是小药（按包装规格区分）
- 自有产品判断：商品名称含"自有"二字

# 竞品参考图合规红线

用户选择"竞品/同行图"作为参考源时，本文件是**硬约束**。参考图只用来读版式，不用来搬内容。

## 一、可迁移（绿色）

这些属于"版式思想"和"通用设计手法"，迁移是行业通例：

| 类别 | 具体内容 |
|---|---|
| 版式骨架 | 模块顺序、分屏数量、每屏高度、分栏比例 |
| 信息层级 | 标题/副标题/正文/注释的层级关系与字号比 |
| 配色逻辑 | 主色占比、对比方式、冷暖倾向、深浅节奏 |
| 构图模板 | 居中、左右分栏、对角线、满版、网格 |
| 通用装饰 | 圆角卡片、虚线分割、序号圆点、标题两侧短翼、渐变方向、阴影强度 |
| 图文关系 | 产品占画面比例、留白量、标注引线方式 |
| 说服结构 | 痛点→方案→证据→场景→规格→信任 的叙事顺序 |
| 句式结构 | "数字+单位+利益"这类通用表达框架 |

## 二、禁迁移（红色）

这些受著作权、商标法、广告法保护或约束，一律不得出现：

| 类别 | 具体内容 | 后果 |
|---|---|---|
| 品牌标识 | 品牌名、Logo、商标、店铺名、域名 | 商标侵权 |
| 广告语 | Slogan、独创的广告句、押韵口号 | 著作权侵权 |
| 视觉作品 | 插画、IP 形象、手绘元素、定制图标 | 著作权侵权 |
| 人物形象 | 模特照片、代言人形象、真人出镜图 | 肖像权 + 著作权 |
| 摄影作品 | 竞品产品实拍图、场景实拍图、细节特写 | 著作权侵权 |
| 数据结论 | 检测数值、实验对比、销量、排名、好评数 | 虚假宣传 + 不正当竞争 |
| 认证标识 | 专利号、认证标、质检标、荣誉证书 | 违法使用认证标志 |
| 原创长句 | 超过 15 字的独特表述，即使改了几个词 | 著作权侵权（实质性相似） |

## 三、广告法违禁词（硬拦截）

`qa_check.py` 会扫描并拦截：

**极限词**：最、第一、顶级、极致、终极、绝无仅有、史无前例、国家级、世界级、冠军、领导者、首创、独一无二

**虚假承诺**：根治、永久、100%有效、包治、无副作用、零风险、绝对

**贬损对比**：秒杀、碾压、完爆、吊打、垃圾（对品类的泛指贬损也有风险）

**医疗功效**（食品/用品类尤甚）：治疗、疗效、抗癌、降压、消炎、壮阳

**限时逼单**（无真实依据）：最后一天、即将售罄、涨价在即

## 四、替换策略

遇到红色项时按以下方式替换：

| 原项 | 替换做法 |
|---|---|
| 竞品品牌名 | 换成自家品牌名，或直接删掉该文字层 |
| 竞品 Slogan | 用自家产品事实重写，只借鉴句式长度与位置 |
| 竞品产品图 | 换自家产品实拍图，保持位置与占比不变 |
| 检测数据 | 有自家报告就用；没有就改成非数据型表达或删除该模块 |
| 认证标识 | 只放自家真实持有的，没有就删 |
| 模特形象 | 用自家实拍或换成产品特写/场景空镜 |

## 五、判定流程

学图时对参考图每个可见元素问一句：

1. **它是不是品牌专属的？** 是 → 禁迁移
2. **它是一个事实/数据吗？** 是 → 只能来自自家凭证
3. **它是一种排版手法吗？** 是 → 可迁移
4. **它是通用装饰吗？** 是 → 可迁移，但建议做差异化（改圆角、换色、调比例）

第 4 条建议做差异化的原因：完全一致的装饰 + 完全一致的版式，容易被认定为整体抄袭。**版式学，细节改**，既安全又不损失效果。

## 六、存疑处理

拿不准的元素，写进 `style-spec.json` 的 `open_questions`，出图后交给用户判断。**不要默认可用。**

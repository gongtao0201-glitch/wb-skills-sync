## API 详情

### author_library_by_custom_search_author

- 摘要：通过达人带货商品分类、达人视频分类、达人基础信息和达人关键数据指标多条件组合，筛选出满足条件的达人列表，支持按指定指标排序。列表信息包括：达人昵称、达人抖音号、达人数据指标。

- 参数:

| 查询字段 | 是否必填 | 说明 |
| --- | --- | --- |
| category_id | 否 | 商品名称，可填写商品品类名称或ID(示例：食品饮料、护肤品），非必填 |
| star_category | 否 | 达人视频分类名称或ID(示例：亲子、穿搭），非必填 |
| gender | 否 | 达人性别：-1（不限）、0（男性）、1（女性），非必填 |
| age | 否 | 达人年龄区间，可选值：18-23、24-30、31-40、41-50、50-，单选，非必填 |
| province | 否 | 达人省份，如：福建省，仅支持单个省份，非必填 |
| fans_gender | 否 | 达人粉丝画像：-1（不限）、0（粉丝男性居多）、1（粉丝女性居多），非必填 |
| fans_age | 否 | 达人粉丝年龄区间，可选值：18-23、24-30、31-40、41-50、50-，单选，非必填 |
| fans_province | 否 | 达人粉丝省份，如：福建省，仅支持单个省份，非必填 |
| fans_city_level | 否 | 达人粉丝城市等级：-1（不限）、0（新一线）、1（一线）、2（二线）、3（三线）、4（四线）、5（五线），单选，非必填 |
| fans_top_consumer_group | 否 | 达人粉丝八大人群画像：精致妈妈、小镇青年、新锐白领、都市蓝领、GenZ、小镇中老年、都市银发、资深中产，单选，非必填 |
| author_type | 否 | 达人类型：0（不限）、1（直播达人）、2（视频达人），非必填 |
| verification_type | 否 | 达人认证类型：0（不限）、1（黄V达人）、2（蓝V达人），非必填 |
| follower_count | 否 | 粉丝数区间，格式最小值-最大值（如0-1000），非必填 |
| active_fans_range | 否 | 近30天活跃粉丝数区间，格式最小值-最大值（如0-1000），非必填 |
| is_brand_self_author | 否 | 填1筛选出品牌自营号，非必填 |
| is_shop_author | 否 | 填1筛选出商家自营号，非必填 |
| author_self_play | 否 | 填1筛选出达人号，非必填 |
| contact | 否 | 填1筛选出简介里有联系方式的达人，非必填 |
| take_product_method | 否 | 带货方式：0（不限）、1（视频带货为主）、2（直播带货为主）、4（图文带货为主），非必填 |
| take_product_level | 否 | 近30天带货销售额区间，格式最小值-最大值（如0-1000），非必填 |
| take_product_price | 否 | 带货商品价格区间，格式最小值-最大值（如0-1000），非必填 |
| jx_level | 否 | 抖音精选联盟带货等级，多选以逗号分隔（如：1,2,3），非必填 |
| first_live_time | 否 | 达人首次开播时间：3（近3天）、7（近7天）、15（近15天）、30（近30天）、90（近90天）、180（近180天）、180+（超过180天），单选，非必填 |
| first_aweme_time | 否 | 达人首次发布视频时间：3（近3天）、7（近7天）、15（近15天）、30（近30天）、90（近90天）、180（近180天）、180+（超过180天），单选，非必填 |
| main_live_flow_struct_type | 否 | 达人直播流量主要来源：0（不限）、1（短视频引流为主）、2（关注为主）、3（推荐Feed流为主）、4（付费为主）、5（其他）、6（搜索为主），单选，非必填 |
| has_brand_exclusive_live | 否 | 填1筛选出有品牌专场直播的达人，非必填 |
| is_ai_author | 否 | 填1筛选出内容主要为AI生成的达人，非必填 |
| clue_author_flag | 否 | 填1筛选出视频内容线索获客型账号，非必填 |
| sort | 否 | 排序字段：follower_count（粉丝数）、inc_follower（粉丝增量）、total_amount_30（近30天销售额）、aweme_total_amount_30（近30天视频销售额）、live_total_amount_30（近30天直播销售额），非必填 |
| page | 否 | 页码，默认为第1页（每页返回50条），非必填 |

### author_library_by_brand_name_product_name_author_name_recommend_author

- 摘要：通过业务场景推荐达人，支持的业务场景包括：按品牌名称推荐可合作的营销种草达人，按商品名称推荐可合作的直播带货达人、按商品名称推荐可合作的视频带货达人、推荐与达人相似的其他达人。支持按粉丝数、粉丝年龄性别、场均销售额、视频平均销量等条件筛选推荐达人。若用户找达人场景满足业务场景（如找品牌合作种草达人，找具备潜力卖某个商品的达人、找相似达人、找指定账号的对标达人等），优先使用本接口，其余情况使用自定义找达人接口

- 参数:

| 查询字段 | 是否必填 | 说明 |
| --- | --- | --- |
| recommend_type | 是 | 推荐场景：1（按品牌名称推荐潜力合作的视频种草达人）、2（按商品名称推荐潜力合作的直播带货达人）、3（按商品名称推荐潜力合作的视频带货达人）、4（推荐与达人相似的其他达人），必填 |
| product_word | 否 | recommend_type=2和3时必需填写，填写商品词（示例：洗面奶、牛奶面包） |
| brand_codes | 否 | recommend_type=1时必需填写，填写品牌ID/品牌名称（示例：韩束、洗面奶、牛奶面包） |
| author_ids | 否 | recommend_type=4时必需填写，填写参考达人ID/达人名称，多个用英文逗号分隔 |
| follower_count | 否 | 粉丝数区间，格式最小值-最大值（如0-1000），非必填 |
| fans_gender | 否 | 填0筛选出粉丝男性居多的达人，填1筛选出粉丝女性居多的达人，非必填 |
| fans_age | 否 | 达人粉丝年龄区间，可选值：18-23、24-30、31-40、41-50、50-，单选，非必填 |
| live_average_amount | 否 | 直播场均销售额区间，格式最小值-最大值（如0-1000），recommend_type=2时有效，非必填 |
| aweme_average_amount | 否 | 视频平均销售额区间，格式最小值-最大值（如0-1000），recommend_type=3时有效，非必填 |
| page | 否 | 页码，默认为第1页（每页返回50条），非必填 |

- 枚举值:

`recommend_type`:

| 取值 | 含义 |
| --- | --- |
| 1 | 根据品牌推荐营销种草达人 |
| 2 | 根据商品词推荐直播带货达人 |
| 3 | 根据商品词推荐视频带货达人 |
| 4 | 根据达人推荐其他相似达人/对标达人 |

`fans_gender`:

| 取值 | 含义 |
| --- | --- |
| -1 | 不限 |
| 1 | 男性居多 |
| 2 | 女性居多 |

`fans_age`:

| 取值 | 含义 |
| --- | --- |
| 18-23 | 18-23岁 |
| 24-30 | 24-30岁 |
| 31-40 | 31-40岁 |
| 41-50 | 41-50岁 |

### author_related_live_list

- 摘要：获取指定达人在周期内开播的直播列表，列表信息包括：直播基础信息及直播数据指标。

- 参数:

| 查询字段 | 是否必填 | 说明 |
| --- | --- | --- |

| start_date | 是 | 开始时间，必填 |
| end_date | 是 | 结束时间，必填 |
| sort | 否 | 排序字段：amount（销售额）、volume（销量）、begin_time（开播时间）、total_user（场观），非必填 |
| page | 否 | 页码，默认为第1页（每页返回10条），非必填 |

- 枚举值:

`sort`:

| 取值 | 含义 |
| --- | --- |
| begin_time | 开播时间 |
| total_user | 观看人次 |
| live_penetration_rate | 直播穿透率 |
| user_peak | 人气峰值 |
| user_value | uv价值 |
| volume | 销量 |
| amount | 销售额 |

示例:

```json
{
  "author_id": "iTA31SmRF1C6TRHxm1z05A",
  "start_date": "2025-01-21",
  "end_date": "2025-02-19"
}
```

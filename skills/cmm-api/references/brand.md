## API 详情

### brand_key_metrics_live_video_author_shop_sales_data_daily_detail

- 摘要：获取指定品牌在周期内的关键数据指标明细，按日返回各数据指标值，包括品牌数据、销售数据、关联达人数据、关联小店数据、关联直播数据、关联视频数据。

- 参数:

| 查询字段 | 是否必填 | 说明 |
| --- | --- | --- |
| brand_code | 是 | 指定单个品牌ID/品牌名称，必填 |
| start_time | 是 | 开始时间，必填 |
| end_time | 是 | 结束时间，必填 |
| category_ids | 否 | 商品分类ID/商品分类名称，多选时按逗号分隔（示例：运动鞋,运动服），仅当关注品牌指定类目数据时填写，非必填 |
| page | 否 | 页码，默认为第1页（每页返回31条），非必填 |

示例:

```json
{
  "brand_code": "0555191359670",
  "start_time": "2025-02-14",
  "end_time": "2025-02-14"
}
```

### brand_top_selling_brand_rank_period

- 摘要：获取历史周期的品牌热销榜单，榜单按周期内品牌销售额降序取TOP品牌列表，列表包括品牌基础信息、品牌销售数据。

- 参数:

| 查询字段 | 是否必填 | 说明 |
| --- | --- | --- |
| day_type | 是 | 榜单周期类型：day（日榜）、week（周榜/大促周期）、month（月榜）、season （季度榜）、half_year（半年榜）、year（年榜），必填 |
| day | 是 | 榜单周期，示例：2025-02-23（日榜周期），20250217-20250223（周榜周期）、202501（月榜周期），202601-202612（季度/半年/年周期），20260515-20260618（大促周期，确保数据查询范围与【蝉妈妈大促数据周期】一致），必填 |
| big_promotion | 否 | 填1表示week为大促周期，只支持系统提供【蝉妈妈大促数据周期】，其余大促请勿使用大促周期查询。非必填 |
| category_id | 否 | 商品分类ID/商品分类名称(示例：食品饮料、护肤品），非必填 |
| sale_way | 否 | 带货方式：1（直播带货为主）、2（视频带货为主），非必填 |
| channel_brand | 否 | 填1筛选品牌号销售为主的品牌，非必填 |
| channel_shop | 否 | 填1筛选商家号销售为主的品牌，非必填 |
| channel_author | 否 | 填1筛选达人号销售为主的品牌，非必填 |
| page | 否 | 页码，默认为第1页（每页返回50条），非必填 |

- 枚举值:

`day_type`:

| 取值 | 含义 |
| --- | --- |
| day | 日榜 |
| week | 周榜/大促 |
| month | 月榜 |

`sale_way`:

| 取值 | 含义 |
| --- | --- |
| 0 | 不限 |
| 1 | 直播带货为主的品牌 |
| 2 | 视频带货为主的品牌 |

`channel_brand`:

| 取值 | 含义 |
| --- | --- |
| 0 | 不限 |
| 1 | 筛选品牌自营号带货为主的品牌 |

`channel_shop`:

| 取值 | 含义 |
| --- | --- |
| 0 | 不限 |
| 1 | 筛选商家自营号带货为主的品牌 |

`channel_author`:

| 取值 | 含义 |
| --- | --- |
| 0 | 不限 |
| 1 | 筛选达人号带货为主的品牌 |

示例:

```json
{
  "day_type": "day",
  "day": "2025-02-23"
}
```

### brand_library_custom_search_brand

- 摘要：通过品牌品牌基础信息和品牌关键数据指标多条件组合，筛选出满足条件的品牌列表，支持按指定指标排序。列表信息包括：品牌名称、品牌logo、品牌数据指标。

- 参数:

| 查询字段 | 是否必填 | 说明 |
| --- | --- | --- |
| category_id | 否 | 商品名称/商品分类，可填写商品品类名称或ID(示例：食品饮料、护肤品、牙膏），非必填 |
| day | 否 | 可选查询周期：day（昨天）、week（近7天）、month（近30天），非必填 |
| duration_avg_amount | 否 | 周期内销售额区间，格式最小值-最大值（如0-1000），非必填 |
| amount_range_30 | 否 | 周期内销量区间，格式最小值-最大值（如0-1000），非必填 |
| author_sum_30 | 否 | 关联达人数区间，格式最小值-最大值（如0-1000），非必填 |
| channel_brand | 否 | 填1筛选品牌号销售为主的小店，非必填 |
| channel_shop | 否 | 填1筛选商家号销售为主的小店，非必填 |
| channel_author | 否 | 填1筛选达人号销售为主的小店，非必填 |
| live_sale_way_rate | 否 | 填51筛选直播带货为主的品牌，非必填 |
| aweme_sale_way_rate | 否 | 填51筛选视频带货为主的品牌，非必填 |

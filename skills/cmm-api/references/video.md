# 视频 API 参考

仅当用户的 CMM 请求主要属于该实体领域时使用此文件。

## 分类默认查询字段

适用时使用该分类的默认查询字段。

## API 详情

### video_library_custom_search_video

- 摘要：核心用途：通过关键词自定义搜索和多条件筛选热门视频。注意：本接口是唯一支持常规视频关键词检索的接口（视频榜单类接口均不支持关键词）。当用户意图包含“视频标题关键词”、“主题”或“特定事件”（如：搜XX视频、找关于XX的视频）时，必须且只能使用此接口。支持结合时间、基础信息、互动指标等组合筛选并排序。

- 参数:

| 查询字段 | 是否必填 | 说明 |
| --- | --- | --- |
| keyword | 否 | 视频标题关键词（示例：拆箱）。注意：只要用户提到了具体的视频标题关键词或主题，必须优先调用此接口，非必填 |
| create_start_time | 是 | 开始时间，必填 |
| create_end_time | 是 | 结束时间，必填 |
| star_category | 否 | 视频分类名称或ID，非必填 |
| follower_count | 否 | 达人粉丝数区间，格式最小值-最大值（如0-1000），非必填 |
| digg | 否 | 视频点赞数区间，格式最小值-最大值（如0-1000），非必填 |
| durations | 否 | 视频时长，单位秒，可选：0-15、15-30、30-60、60-，非必填 |
| gender_type | 否 | 观众画像-性别：-1（不限）、0（粉丝男性居多）、1（粉丝女性居多），非必填 |
| age_types | 否 | 观众画像-年龄，2（18-23岁）、3（24-30岁）、4（31-40岁）、5（41-50岁）、6（>50岁）单选，非必填 |
| province | 否 | 观众画像-省份，如：福建省，仅支持单个省份，非必填 |
| blue_words | 否 | 看后搜小蓝词关键词，非必填 |
| is_ai | 否 | 填1筛选出AI生成的视频，非必填 |
| is_star_aweme | 否 | 填1筛选出星图合作视频，非必填 |
| aweme_graph_type | 否 | 填1筛选出图文视频，非必填 |
| is_hot | 否 | 填1筛选出关联了抖音热点的视频，非必填 |
| is_cooperation_aweme | 否 | 填1筛选出共创视频，非必填 |
| is_live_author | 否 | 填1筛选出有直播带货的达人视频，非必填 |
| sort | 否 | 排序字段：digg_count（点赞数）、comment_count（评论数）、share_count（转发数），非必填 |
| page | 否 | 页码，默认为第1页（每页返回50条），非必填 |

- 枚举值:

`durations`:

| 取值 | 含义 |
| --- | --- |
| -15 | <15秒 |
| 15-30 | 15-30秒 |
| 30-60 | 30-60秒 |
| 60- | >60秒 |

`gender_type`:

| 取值 | 含义 |
| --- | --- |
| 0 | 男性居多 |
| 1 | 女性居多 |
| -1 | 全部 |

`age_types`:

| 取值 | 含义 |
| --- | --- |
| 2 | 18-23岁 |
| 3 | 24-30岁 |
| 4 | 31-40岁 |
| 5 | 41-50岁 |
| 6 | >50岁 |

`sort`:

| 取值 | 含义 |
| --- | --- |
| digg_count | 点赞数 |
| comment_count | 评论数 |
| share_count | 转发数 |

示例:

```json
{
  "create_start_time": "",
  "create_end_time": ""
}
```

### video_library_custom_search

- 摘要：通过关键字、带货分类等多条件组合，筛选出满足条件的千川投放渠道的跑量投放视频广告素材，支持按指定指标排序。列表信息包括：视频信息、视频文案及视频数据指标。

- 参数:

| 查询字段 | 是否必填 | 说明 |
| --- | --- | --- |
| keyword | 否 | 视频标题/达人名称/直播间标题/商品/品牌/口播文案关键词（示例：拆箱），非必填 |
| start_date | 是 | 开始时间，必填 |
| end_date | 是 | 结束时间，必填 |
| category_id | 否 | 带货商品分类ID/带货商品分类名称(示例：食品饮料、护肤品），非必填 |
| sort_field | 否 | 排序字段：nearly_3_play_count（近3日播放量）、digg_count（点赞数），total_play_count（总播放量），run_score（蝉妈妈跑量分）非必填 |
| type | 否 | 素材类型：：-1（不限）、1（直播引流广告素材）、2（商品挂链广告素材），非必填 |
| page | 否 | 页码，默认为第1页（每页返回50条），非必填 |

- 枚举值:

`sort_field`:

| 取值 | 含义 |
| --- | --- |
| nearly_3_play_count | 近3日播放量 |
| total_play_count | 总播放量 |
| digg_count | 点赞数 |
| run_score | 跑量分 |

`type`:

| 取值 | 含义 |
| --- | --- |
| -1 | 不限 |
| 1 | 直播引流广告素材 |
| 2 | 商品挂链广告素材 |

示例:

```json
{
  "start_date": "",
  "end_date": ""
}
```

- 摘要：获取历史周期的热销视频榜单，榜单按照周期内视频带货销量降序取TOP视频列表，列表包括：视频基础信息、视频互动数据、视频销售数据。绝对限制：本榜单接口不支持任何形式的关键词、商品名、主题检索！如果用户表达了想看“某个具体商品（如：洗面奶）”或“包含某关键词”的带货榜单，禁止调用此接口，必须去调用 api_id: 64 (带货视频库)。

| --- | --- | --- |
| day_type | 是 | 榜单周期类型：day（日榜）、week（周榜）、month（月榜），必填 |
| day | 是 | 榜单周期，示例：2025-02-23（日榜周期），20250217-20250223（周榜周期）、202501（月榜周期），必填 |
| category_id | 否 | 带货商品分类ID/带货商品分类名称(示例：食品饮料、护肤品），非必填 |
| page | 否 | 页码，默认为第1页（每页返回50条），非必填 |

- 枚举值:

`day_type`:

| 取值 | 含义 |
| --- | --- |
| day | 日榜 |
| week | 周榜 |
| month | 月榜 |

示例:

```json
{
  "day_type": "day",
  "day": "2025-02-23"
}
```

| page | 否 | 页码，默认为第1页（每页返回50条），非必填 |

- 枚举值:

| 取值 | 含义 |
| --- | --- |

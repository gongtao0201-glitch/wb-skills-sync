## API 详情

### category_analysis_by_custom_product_keyword

- 摘要：通过商品名称关键词查询周期内销量TOP2000商品，统计分析包括销售数据、市场规模与热度（关联达人/直播/视频数、搜索指数）、竞争态势（商品/品牌/小店集中度）、销售渠道分布、价格带分布、观众画像、成交画像、商品评价、营销关键词、热销属性、飙升属性分析。

- 参数:

| 查询字段 | 是否必填 | 说明 |
| --- | --- | --- |
| keyword | 是 | 商品名称关键词（示例：牛奶面包、玻尿酸精华），必填 |
| multi_category_id | 是 | 指定单个商品分类ID，必填，默认-1 |
| start_time | 是 | 开始时间，必填 |
| end_time | 是 | 结束时间，必填 |

示例:

```json
{
  "keyword": "唇膏",
  "start_time": "2025-02-19",
  "end_time": "2025-03-20",
  "multi_category_id": "-1"
}
```

### category_analysis_by_product_category_name

- 摘要：通过商品品类名称查询周期内销量TOP2000商品，统计分析包括销售数据、市场规模与热度（关联达人/直播/视频数、搜索指数）、竞争态势（商品/品牌/小店集中度）、销售渠道分布、价格带分布、观众画像、成交画像、商品评价、营销关键词、热销属性、飙升属性分析。仅支持查询指定范围的商品分类，**若无精准匹配的分类则优先使用 API 品类分析_按自定义商品关键词查询**

- 参数:

| 查询字段 | 是否必填 | 说明 |
| --- | --- | --- |
| multi_category_id | 是 | 指定单个商品品类名称或ID，必填，仅支持以下品类名称或者品类名称对应的ID：母婴用品、本地生活、生鲜蔬果、钟表配饰、汽配摩托、二手商品、家具建材、美妆护肤、3C数码、家居家纺、礼品文创、运动户外、图书教育、玩具乐器、食品饮料、鞋靴箱包、日用百货、厨卫家电、宠物用品、服饰内衣、鲜花绿植、珠宝饰品、医药保健、原料包装、酒类、生活电器、婴童用品、个护电器、童装、个人护理、大家电、男装、男鞋、滋补品、餐饮具、厨房卫浴、生活用品、女装、蔬菜、海鲜水产、方便速食、厨房电器、五金工具、厨具、零食/坚果/特产、影音娱乐、美妆工具/美容仪器、宠物用品/服饰、奢侈品、家庭清洁、宠物保健、床上用品、女鞋、智能设备、灯饰照明、家居饰品、护肤品、婴童尿裤、居家布艺、箱包、饮料/乳品/咖啡/麦片/冲调、彩妆/香水、宠物食品、绿植园艺、保健品、生活日用、住宅家具、收纳整理、水果及水果制品、成人用品/情趣用品、宠物 |
| start_time | 是 | 开始时间，必填 |
| end_time | 是 | 结束时间，必填 |

示例:

```json
{
  "start_time": "2025-01-04",
  "end_time": "2025-03-05",
  "multi_category_id": ""
}
```
